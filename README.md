## Features

- **Display Tasks:** View all tasks retrieved from the database.
- **Add Task:** Create a new task with title and description.
- **Edit Task:** Modify existing task details.
- **Toggle Completion Status:** Mark tasks as completed or incomplete.
- **Delete Task:** Remove a task from the database.
- **Error & Status Notifications:** Real-time user feedback.
- **Team Contributor Page:** Dynamic loading of contributor data.
